# Antigravity Rules

## Core Principles
* **Performance First:** All code must be optimized for speed and low resource consumption. Avoid unnecessary re-renders and heavy dependencies.
* **Mobile-First Design:** Development should start with small screens in mind. Adaptability and touch responsiveness take priority over desktop layout.
* **Multi-site:** This is for multiple sites and perhaps several different themes with varied templates.

## Guidelines
1.  **Thinking Process:** Before writing code, analyze the impact on Bundle Size.
2.  **CSS/Styling:** Use utilities that favor responsive design (e.g., minimal breakpoints first).
3.  **Optimization:** Implement lazy loading and image optimization by default.
4.  **Code Organization:** Organize code in a clear and maintainable way. Use reusable components and separate business logic from presentation.
